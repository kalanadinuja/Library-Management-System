**Library Management System** is a full‑stack web application built using the **MERN stack**. It allows librarians to manage books, members, and borrowing transactions with a clean and responsive interface.

---

## 📖 Overview

A web‑based library management system designed to digitize and simplify library operations including book inventory, member registration, and borrow/return tracking.

## 🛠 Technologies Used

- **MongoDB** – NoSQL database
- **Express.js** – backend framework
- **React.js** – frontend library
- **Node.js** – runtime environment
- **JavaScript** – core language
- **CSS3 / HTML5** – styling and markup

## ✨ Key Features

- 📚 Book inventory management (add, edit, delete books)
- 👥 Member registration and management
- 🔄 Borrow and return tracking (with due dates)
- 🔍 Search and filter functionality (by title, author, genre)
- 📱 Responsive design for all devices
- 📊 Admin dashboard with statistics (total books, active members, overdue items)
- 🔐 User authentication (admin / librarian roles)
