# Library-Management-System
A full‑stack library management system built with the MERN stack (MongoDB, Express, React, Node.js). Users can browse books, borrow up to 3 books at a time, add books to a wishlist, and manage their borrowed books in a personal shelf with return countdown. Admin dashboard allows adding, deleting, and managing books.
